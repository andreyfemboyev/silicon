# SILICON — Architecture Development Studio

**Design. Simulate. Execute.**

[![CI](https://github.com/andreyfemboyev/silicon/actions/workflows/ci.yml/badge.svg)](https://github.com/andreyfemboyev/silicon/actions/workflows/ci.yml) [![MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[Downloads and releases](https://github.com/andreyfemboyev/silicon/releases) · [Release notes](docs/RELEASE-v0.1.0-alpha.md)

SILICON is an MIT-licensed, offline-first workbench for digital logic and custom processor architectures. The Tauri 2 desktop app provides a schematic editor, an ISA workshop, a Monaco assembly editor, an instruction debugger, and a signal analyzer. The Rust CLI uses the same engines and runs without Node.js, Tauri, or a desktop environment.

## Run the first project

```sh
cargo build --locked -p silicon
target/debug/silicon init fibonacci.silicon.json --reference micro-8
target/debug/silicon validate fibonacci.silicon.json
target/debug/silicon assemble fibonacci.silicon.json -o fibonacci.bin --symbols fibonacci.symbols.json
target/debug/silicon disassemble fibonacci.silicon.json fibonacci.bin
target/debug/silicon run fibonacci.silicon.json --memory 240
target/debug/silicon trace fibonacci.silicon.json --history 8
target/debug/silicon simulate fibonacci.silicon.json --ticks 16 --vcd fibonacci.vcd
```

The program stores 21 at byte address 240. The circuit in that project is an independent clock, counter, adder, and register example. Select **MICRO-8-CPU** for the executable circuit CPU and its matching instruction-level program.

On the desktop, open **ISA Workshop** to edit the ISA JSON. Apply the architecture and use **Assembly** to assemble source and inspect the generated bytes and symbols. Use **Execution Lab** to step, reverse, set breakpoints and watchpoints, and inspect memory. **Schematic** accepts library components by click or drag. Connect an output to an input or choose the upstream node in the inspector. Simulate the circuit and switch to **Signal Analyzer** to inspect recorded transitions or export VCD. **Save** writes one project JSON file that **Open** restores.

### Examples

| Project | Instruction-level program | Circuit |
| --- | --- | --- |
| [MICRO-8](examples/micro-8.json) | Fibonacci, memory store, conditional branch | Counter and registered sum |
| [MICRO-8 circuit CPU](examples/micro-8-cpu.json) | Register initialization, ADD, flag updates, HALT | ROM-fed subset processor with matching test |
| [SILICON-16](examples/silicon-16.json) | Subroutine, stack, virtual console | 16-bit counter and registered sum |
| [SILICON-32](examples/silicon-32.json) | Sort three words, store result in memory | 32-bit counter and registered sum |

### Commands

Run `silicon --help` or `silicon <command> --help` for arguments. Global `--json` emits structured command results and runtime errors. `silicon test` runs embedded reference checks. `silicon benchmark --iterations 100` reports timings measured on the current machine.
