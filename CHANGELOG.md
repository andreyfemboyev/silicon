# Changelog

## v0.1.0-alpha

- Rust core and standalone Linux/Windows CLI source.
- Versioned architecture and project JSON, assembler, disassembler, and bounded instruction execution.
- Three documented reference architectures and a verified MICRO-8 SET/ADD/HALT circuit fixture.
- Four-state event-driven logic, nested circuit instances, clocked storage, contention diagnostics, and VCD export.
- Tauri 2 desktop workbench with schematic editing, Monaco, debugger, and signal analysis.
- Core, CLI, IPC, and browser frontend tests plus GitHub Actions release configuration.
