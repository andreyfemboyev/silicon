# Roadmap

## v0.1.0-alpha

The alpha provides a native workspace that loads and saves projects, validates and assembles a defined architecture, runs a reversible debugger, and simulates and visualizes circuits. Three reference ISAs and one tested subset circuit CPU ship with the source.

## Following the alpha

1. Expand the circuit CPU, link assembled programs directly into ROM and verify each added instruction against the instruction engine.
2. Add a module library and recursive graphical schematic editing.
3. Extend the ISA with encoding families, mapped devices, per-flag behavior and interrupts.
4. Add streaming simulation captures, trigger acquisition and persistent debugger checkpoints.
5. Qualify Windows and Linux installers on clean offline machines.
